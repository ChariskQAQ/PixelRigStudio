# Pixel Rig Studio

[English](README.en.md) | 简体中文

一款面向 Windows 的离线像素绘画与动画制作工具。可以逐帧绘画，也可以把角色部件绑定到二维骨骼、摆姿势、烘焙成像素帧，再手工修整；场景工作区用于将背景、角色动作和道具编排成像素短片。

当前版本：**v0.5.2 试用版 · Windows x64**。应用界面和随包详细手册为简体中文。

**[下载 v0.5.2](https://github.com/ChariskQAQ/PixelRigStudio/releases/tag/v0.5.2)** · [历史版本](https://github.com/ChariskQAQ/PixelRigStudio/releases) · [反馈问题](https://github.com/ChariskQAQ/PixelRigStudio/issues)

这个项目还在打磨中，欢迎从示例开始试用。骨骼可以帮助安排动作，但旋转后的像素轮廓和接缝仍需要检查和修整。

## 下载与运行

1. 在上方下载页的 Assets 中选择 `PixelRigStudio-v0.5.2-Windows-x64.zip`。
2. **完整解压**到可写文件夹，运行 `PixelRigStudio.exe`。
3. 保留 DLL、`resources`、`locales` 等同目录文件，不能只复制 EXE。
4. 不需要安装 Node.js、Blender，不需要账户或联网。视频编码建议使用 Windows 10 22H2 或 Windows 11。

主 ZIP 已包含离线编码器、四个示例、中文手册，以及两款可选插件；单独的插件 ZIP 仅用于更新。发布页的 `SHA256SUMS-v0.5.2.txt` 用于校验主包、插件和两份 README。

程序尚未代码签名，也没有自动更新。请从本仓库下载，重要工程保留备份。公开仓库只分发说明与软件包，**主程序源码不公开**。

## 先完成一个角色动作

1. 首页打开「绑定与挥手练习」，先按 `Ctrl+S` 保存副本。
2. 保持「绘制部件」，在对象树选中未绑定的左前臂图片行，右键「绑定到骨骼…」，选择左前臂骨骼；也可拖到对应骨骼发起绑定。
3. 切换「摆姿势」，选前臂，按 `K` 拖动末端调整手的位置。松开记录当前帧姿势，`Esc` 取消拖动。
4. 到后面的帧安排不同姿势，选择保持或线性插值，播放检查节奏。
5. `Shift` 选择连续帧，调整帧时长，再从「动画 → 烘焙动画…」生成普通像素图层。
6. 进入「逐帧修整」，使用画笔修改细节，保存 `.pxrig`，再导出 PNG、PNG 序列或精灵表及 JSON。

「绘制部件」修改所有姿势使用的源图；「逐帧修整」修改烘焙后的当前帧。再次烘焙会创建新结果，保留旧结果与手工修改。

## 可以做什么

| 工作区 | 主要用途 |
| --- | --- |
| 角色／精灵 | 铅笔、橡皮、填充、选区、笔刷预设、色板与选色器；图层和骨骼统一对象树；FK、两段式 IK、姿势插值、洋葱皮、烘焙与修整 |
| 变换与布局 | 当前普通像素图层选区／整帧自由变换：平移、缩放、旋转、斜切；基础骨长与部件伸缩；面板停靠、浮动、移动和拖边缩放 |
| 场景动画 | 复用背景、角色片段和道具，安排片段与对象关键帧、镜头运动、一条参考音轨；导出 MP4、GIF、透明 PNG 序列 |
| 视频抽帧 | 选择本地视频的时间范围、采样率和像素尺寸，生成场景动作素材；不自动移除背景或转换成分层像素画 |
| 三维转精灵 | 内置 GLB／FBX；PMX 2.0／VMD 通过插件，设置视角、模型尺寸、动作和表情，再生成像素帧 |
| 图片导入 | PNG、固定网格精灵表、有限范围的 PSD 分层导入；复杂 PSD 需选择文件中已有的合成图 |

场景入门：首页打开「场景短片示例」，播放查看背景、两个人偶、镜头与声音，再修改对象位置和时间轴。素材嵌入场景，移走原文件后仍能播放和导出；动作需要修整时先修改角色工程，再更新场景素材。

骨骼插值只调整变换，不自动补画两张图片。IK 是摆姿势工具，不提供持续固定脚。场景内移动对象不会重新驱动已烘焙的物理。

## 可选插件

主 ZIP 的 `可选插件` 目录中附带：

| 插件 | 版本 | 能力 |
| --- | --- | --- |
| `pixel-rig-physics-1.2.7.zip` | 1.2.7 | 二维部件弹性跟随、重力与简化碰撞；保持位图形状，不提供软体、布料或挤压拉伸 |
| `pixel-rig-pmx-1.2.6.zip` | 1.2.6 | PMX 2.0、VMD 骨骼动作、IK 与基础表情；不启用 MMD 物理，不支持 PMX 2.1 |

安装：首页或「工具 → 插件管理…」→「安装本地插件…」→ 选择 ZIP（不用解压）→ 启用 → 保存并重启。随后从画布右侧的「物理」或「PMX」标签进入。两款插件默认不安装、不启用，可同时启用。

两款插件使用 API 1，兼容本版 0.5.2。已有物理 1.2.6／PMX 1.2.5 也可继续使用；更早且兼容上界为 0.4.10 的插件需要更新。更新时停用并重启、卸载旧包，再安装随包 ZIP、启用并重启。卸载不会删除工程参数或已生成像素。

插件是可执行代码，只安装可信来源。Blender Python 插件不兼容；二维物理插件不会给 PMX 添加三维物理。

## 保存和已知边界

- 工程使用 `.pxrig`：普通角色格式 3、场景格式 4、骨长联动角色格式 5；继续读取旧角色格式 1／2／3／5。新格式旧软件可能无法打开，升级前保留副本。
- 普通保存保留 `.bak`，修改后每 60 秒写入恢复副本。保存取消或失败时继续保留工程。
- 角色画布不超过 512×512、500 帧、150 图层／组、256 根二维骨骼。场景不超过 512×512、60 秒、16 个对象，帧率为 6／8／12／24fps。
- PSD 为 RGB、8 位、512×512 以内、最多 150 图层／组；复杂混合、蒙版、文字等会显示兼容报告，不静默忽略。只导入，不回写 PSD。
- MP4／GIF 使用背景色，透明素材使用 PNG 序列；MP4 并非像素无损编码。输出可整数倍放大。
- VMD 只用于 PMX；不做跨骨架动作重定向。三维渲染不保证复现 Blender 或 MMD 的完整效果。
- 手册部分截图来自较早版本，以文字和当前菜单为准。界面尚无英文翻译，英文 README 不代表英文应用界面。
