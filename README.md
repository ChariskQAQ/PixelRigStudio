# Pixel Rig Studio

Windows 离线像素绘图与二维骨骼动画编辑器。界面参考 Adobe 创作工具的深灰工作区、工具属性栏、文档标签、可调整面板及时间轴布局。

当前版本 **0.3.5 内部试用版**，包含可选三维转精灵工作区、模型基础编辑、圆盘选色器、色板管理及图层 / 骨骼 / 时间轴右键菜单。支持 GLB／FBX、PMX 2.0／VMD、基础表情与 XYZ 变换；工程嵌入源素材，关闭统一使用深色保存确认。保留 IK、逐帧编辑及 Steam 分发准备。

这是 v0.3.5 的软件分发仓库，仅保留 README 和 Windows 软件包。问题反馈可提交到 [GitHub Issues](https://github.com/ChariskQAQ/PixelRigStudio/issues)，请附版本、操作步骤、预期与实际结果及截图。

## 启动

[下载 v0.3.5 Windows x64 软件包](https://github.com/ChariskQAQ/PixelRigStudio/releases/download/v0.3.5/PixelRigStudio-v0.3.5-Windows-x64.zip) · [版本发布页](https://github.com/ChariskQAQ/PixelRigStudio/releases/tag/v0.3.5)

1. 下载 `PixelRigStudio-v0.3.5-Windows-x64.zip`。
2. 完整解压，在版本文件夹中运行 `PixelRigStudio.exe`。
3. 保留同目录的 DLL、resources、locales 等配套文件，无需安装 Node.js 或 Blender。运行时完全离线。

## 制作流程

1. 启动时加载原创「巡游者」示例，包含 12 个像素部件、13 根骨骼和 12 帧动画。
2. 在「绘制部件」模式修改源像素；也可新建透明工程，每个部件独占一个图层。
3. 在「骨骼」菜单创建自定义骨骼或人形模板。选中普通像素图层，使用「图层 → 绑定到骨骼」。
4. 切换到「摆姿势」，用 R 旋转骨骼，或选前臂、小腿后用 K 拖动 IK 末端。拖动自动记录当前帧姿势；Esc 取消。根节点拖动控制整体位移。
5. 使用「动画 → 姿势插值」选择保持或线性插值；使用时间轴播放检查动作。
6. Shift 选择帧范围，批量复制、删除、修改时长或烘焙。拖动菱形移动姿势，Ctrl 拖动复制；已有姿势需要确认替换。
7. 烘焙生成独立像素图层组，进入「逐帧修整」。再次生成会保留旧结果和手工修改，并隐藏旧组。
8. 保存为 `.pxrig` 工程，或在「文件 → 导出」生成 PNG、PNG 序列、精灵表及 JSON。源部件模式下，P 工具拖动枢轴或部件；修改枢轴保持像素位置。

骨骼旋转采用最近邻采样。任意角度可能产生锯齿和接缝，最终轮廓需要手工修整。导出不包含骨骼、洋葱皮或网格。

三维流程：从「工具 → 三维转精灵」导入角色、选择动作／表情、设置视角和尺寸，再生成像素帧修整。无需 Blender；PMX 物理关闭，VMD 仅用于 PMX。复杂第三方模型的兼容性需要实际测试。

导入按钮下方提供模型基础编辑：百分比缩放、滑杆、尺寸预设、左右转向和适合画面；「XYZ 移动与旋转…」定位精确参数。滑杆实时预览、松开一次提交，Esc 取消。修改随工程保存并支持撤销，原模型文件保持不变。

右侧「颜色 / 色板」可切换：左键选前景色、右键选背景色，色板支持添加、双击编辑、删除、排序和恢复默认。十六进制输入支持 3 / 6 位；色板修改可撤销，并随工程保存，不替换已画好的像素。

点击左侧前景色色块或右侧颜色预览，打开浮动圆盘选色器：色相 / 饱和度圆盘、明度竖条、RGB / HSV / Hex 输入、Alpha 和画布吸管，实时连接画笔颜色与透明度。

## 操作

| 操作                          | 快捷键                     |
| ----------------------------- | -------------------------- |
| 铅笔 / 橡皮 / 填充 / 吸管     | B / E / G / I              |
| 矩形选区 / 移动 / 直线 / 矩形 | M / V / L / U              |
| 骨骼 / 抓手                   | R / H                      |
| 两段式 IK / 调整绑定          | K / P                      |
| 连续帧选择 / 复制关键姿势     | Shift 点击 / Ctrl 拖动菱形 |
| 平移 / 缩放                   | 空格拖动 / Ctrl + 滚轮     |
| 画笔大小                      | [ / ]                      |
| 保存 / 另存为                 | Ctrl+S / Ctrl+Shift+S      |
| 新建 / 打开                   | Ctrl+N / Ctrl+O            |
| 撤销 / 重做                   | Ctrl+Z / Ctrl+Shift+Z      |
| 复制 / 粘贴像素               | Ctrl+C / Ctrl+V            |
| 全选 / 取消 / 清除            | Ctrl+A / Esc / Delete      |
| 上一帧 / 下一帧 / 播放暂停    | ← / → / Enter              |

拖动右侧面板分隔线或时间轴上方分隔线可调整空间。绘画与骨骼拖动各作为一次撤销操作；文本输入时暂停画布快捷键。

## 文件与限制

- `.pxrig` 格式 2 是 ZIP，包含 JSON、无损 PNG 和去重的三维二进制源。继续读格式 1，首次保存默认另存升级副本；旧软件不能打开格式 2。
- 常用画布为 32–256px，当前画布上限 512×512、最多 500 帧、150 个图层、256 根骨骼。
- PNG 精灵表支持固定单元尺寸、间隔和起始偏移。导出布局为横排、竖排或固定列数；单元保持画布尺寸。
- 精灵表最后一行可能包含空白填充单元；JSON 描述实际帧数量。固定网格重新导入会将完整填充单元一起读取。
- 普通保存使用临时文件替换并保留 `.bak`；修改后每 60 秒保存恢复副本，重新启动时可恢复。
- 使用 RGBA 普通合成、FK、刚性绑定和两段式 IK 摆姿势。IK 只支持首尾连接的直接父子骨骼链，写入 FK 角度，不提供持续约束或自动固定脚。网格编辑、GIF、索引色和 Aseprite 工程读写留待后续。
- 三维单资源 32MiB、总资源 64MiB、模型 10 万三角形／1024 根骨骼、贴图 4096²／解码预算 128MiB。支持 GLB／FBX 和 PMX 2.0／VMD；PMX 物理和复杂表情暂未支持。
- 内部像素剪贴板在应用内使用；未接入系统图片剪贴板。
- 目前提供便携版，未做代码签名或自动更新。
