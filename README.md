# Pixel Rig Studio

Windows 离线像素绘画与动画制作工具。可以直接逐帧画，也可以将角色部件绑定到二维骨骼，先摆姿势，再生成像素帧修整；场景工作区可以把背景、角色动作与道具编排成像素短片。

当前版本：**v0.4.2 试用版**。适用 **Windows x64**，运行无需 Node.js、Blender、账户或联网。视频编码器建议在 Windows 10 22H2／Windows 11 上使用。

## 下载与启动

**[下载 v0.4.2 Windows x64](https://github.com/ChariskQAQ/PixelRigStudio/releases/tag/v0.4.2)**

1. 下载 `PixelRigStudio-v0.4.2-Windows-x64.zip`。
2. 完整解压到可写的文件夹。
3. 运行文件夹中的 `PixelRigStudio.exe`。
4. 请保留同目录的 DLL、`resources`、`locales` 等文件，不能只复制 EXE。

主程序包内已有两个可选插件和离线使用说明，无需重复下载插件。发布页另附插件 ZIP，便于单独更新；`SHA256SUMS-v0.4.2.txt` 可用于核对下载文件。

这是试用版，程序尚未代码签名。首次使用建议从示例开始，重要工程保留备份。如 Windows 提示未知发布者，请先确认文件来源和校验值。

本公开仓库只提供发行包和使用说明，**不公开主程序源码**。旧版可从 [历史 Releases](https://github.com/ChariskQAQ/PixelRigStudio/releases) 下载。

## 第一次使用

启动先进入项目首页。可以新建「角色／精灵」或「场景动画」，打开已有 `.pxrig` 工程、导入 PSD，或主动打开示例。

返回首页会保留当前工程、撤销记录、当前帧与视图，点击「继续编辑」返回。最近工程记录只记录实际保存或打开的工程；移除记录不会删除磁盘文件。

### 做一个角色动作

1. 新建角色工程，或打开内置「巡游者」示例。
2. 新角色的头、身体、手臂等部件分别放在图层里。
3. 在「骨骼」菜单创建骨骼或人形模板；选中像素图层，使用「图层 → 绑定到骨骼」。
4. 切换「摆姿势」，用 `R` 旋转骨骼，或选前臂／小腿后用 `K` 拖动两段式 IK 末端。
5. 设置关键姿势和帧时长，用时间轴检查节奏；`Shift` 点击可选择连续范围。
6. 将动作烘焙为普通像素图层，切到「逐帧修整」，修轮廓和接缝。
7. 保存为 `.pxrig`，或导出 PNG、PNG 序列、精灵表与 JSON。

骨骼旋转不会模糊像素，但任意角度会改变轮廓。**生成结果仍需要手工检查**。再次烘焙会创建新结果组，保留之前的修整，并默认隐藏旧组。

### 做一段像素短片

1. 新建「场景动画」，或打开内置街角短片示例。
2. 导入 PNG 背景、PNG 序列，或角色 `.pxrig` 中选定的动作范围／标签。
3. 为对象安排片段起止时间、循环、速度、位置、旋转、缩放与透明度。
4. 使用对象关键帧与镜头位置／缩放关键帧制作运动。
5. 可导入一条 WAV／MP3 参考音轨，调整起点、截取范围和音量。
6. 导出 MP4、GIF 或透明 PNG 序列；输出可整数倍放大。

场景内使用已生成的动作片段，不直接编辑片段像素。修改角色动作后，通过「更新素材」重新导入。移动场景对象不会重新驱动角色挂件物理。

默认 320×180、12fps、10 秒；逻辑画布最大 512×512，支持 6／8／12／24fps、最长 60 秒、最多 16 个对象。MP4／GIF 合成到指定背景色；透明输出使用 PNG 序列。

## 可选插件

两个插件在软件目录的 **「可选插件」** 中，默认不安装、不启用。

### 安装

1. 首页或「工具 → 插件管理…」。
2. 点击「安装本地插件…」，选择对应 ZIP，**不用解压**。
3. 点击「启用」，保存工程后关闭并重新打开软件。
4. 点击画布右缘的「物理」或「PMX」标签展开。

启用、停用在下次启动生效；收起侧栏不等于停用插件。更新旧插件时，先停用并重启，再卸载、安装新版、启用并重启。两个插件可以同时启用。

### 二维物理：`pixel-rig-physics-1.2.0.zip`

选中已绑定部件后，在右侧「物理」面板设置质量、重力、弹性联动、阻尼、物理权重、连接与简化碰撞体。可从「工具 → 部件模拟插件示例…」试用耳朵和挂件联动。

物理保持位图原形，只改变位置和角度，**不包含挤压拉伸、软体或布料**。简化圆形／矩形碰撞不保证高速运动绝不穿透。

### PMX／VMD：`pixel-rig-pmx-1.2.0.zip`

从右侧「PMX」进入三维工作区，再展开三维右缘「PMX」。导入模型后，可调整大小、XYZ、VMD 动作、支持的表情、材质、相机与像素输出。

支持 PMX 2.0、VMD 骨骼动作／IK、顶点与限定组表情。**不启用 MMD 头发／衣服物理，不支持 PMX 2.1**。二维物理插件不会为 PMX 添加三维物理，也不兼容 Blender 的 Python 插件。

GLB／FBX 无需插件；导入现有模型生成像素帧不需要安装 Blender。VMD 仅用于 PMX，不提供跨骨架动作重定向，也不能把二维图片自动变成三维角色。

只安装可信来源的插件。插件是本地可执行代码，不是完整安全沙箱。卸载插件不会清除工程中的参数、源素材和已生成像素。

## PSD 与 PNG 导入

- PSD 支持 RGB、8 位、512×512 以内、最多 150 个图层／组的普通分层内容。
- 复杂混合、蒙版、文字或智能对象等会显示兼容报告；不能可靠分层时，可以选择 PSD 内保存的整张合成位图。
- PSD 文件不修改，导入后另存 `.pxrig`；不支持 PSD 导出、PSB、CMYK、16／32 位或完整 Photoshop 功能。
- 普通 PNG 最大 512×512、文件最大 8MiB；超出当前画布的内容裁切。
- 大精灵表使用「导入精灵表」，按单元尺寸、间隔与偏移切分；文件最大 8MiB，边长最多 16384、最多 3200 万像素，切分后仍受工程预算与帧数限制。

## 保存、恢复与容量

- `Ctrl+S` 保存，`Ctrl+Shift+S` 另存；保存保留上一份 `.bak`。
- 修改后每 60 秒写入恢复副本，重启后可从首页处理。
- 保存取消、失败或保存期间内容发生变化时，工程保持打开。
- 角色工程格式为 3，场景为 4；继续读取旧角色格式 1／2／3。升级旧角色工程首次保存默认另存副本，旧软件不能打开新格式。
- 角色画布最大 512×512，最多 500 帧、150 个图层／组、256 根二维骨骼。
- 工程 ZIP 最大 128MiB；角色部件源图与全部 Cel 合计最多 128MiB RGBA，重复引用分别计数。场景共享像素资源也有 128MiB 解码预算。
- 这些限制是资源预算，不代表达到上限时仍有相同播放性能；建议先使用小样例。

## 常用快捷键

| 操作 | 快捷键 |
| --- | --- |
| 铅笔／橡皮／填充／吸管 | B／E／G／I |
| 矩形选区／移动 | M／V |
| 骨骼／两段式 IK／绑定调整 | R／K／P |
| 平移／缩放 | 空格拖动／Ctrl+滚轮 |
| 保存／另存 | Ctrl+S／Ctrl+Shift+S |
| 撤销／重做 | Ctrl+Z／Ctrl+Shift+Z |
| 上一帧／下一帧／播放暂停 | ←／→／Enter |
| 取消拖拽或未提交调整 | Esc |

文本输入时隔离画布快捷键。详细快捷键与操作以包内说明为准。

## 第三方软件

应用使用 Electron、React、Three.js 等组件；物理和 PMX 插件分别使用 Matter.js、Babylon.js 与 babylon-mmd。许可与说明见包内 `THIRD-PARTY-NOTICES.txt`。

视频编码使用独立进程运行的 LGPL FFmpeg，不使用 libx264。许可证、原始来源和编译选项在 `resources/runtime`；FFmpeg 固定源码、构建配方及依赖源码位置索引在「第三方源码／FFmpeg」。相关资料不代表已经独立复现上游二进制，也不是完整离线重编环境。
